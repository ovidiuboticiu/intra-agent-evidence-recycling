# Publication Checklist

The scientific package is ready to upload as a GitHub repository. Before making it public:

- [ ] Choose a repository name and one-sentence description.
- [ ] Confirm the public author name and contact information, if any.
- [ ] Select a license. Without one, others may view the repository but reuse permissions remain unspecified.
- [ ] Upload the contents of this directory without modifying the frozen v0.4.3 files.
- [ ] Run `sha256sum -c RELEASE_MANIFEST_v0_4_3.sha256` after cloning or downloading the public release.
- [ ] Add the public repository URL and, if created later, the release tag or DOI.
